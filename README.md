# StoryKeeper

Локальный стол ведущего для настольных ролевых игр. Кампании, локации, персонажи, улики, игроки, схема отношений, журнал и заметки хранятся в браузере. Сервер приложению не нужен.

## Запуск

Нужен Node.js 20 или новее — только чтобы раздать файлы. Сама программа написана на HTML, CSS и JavaScript.

```bash
npm install
npm start
```

Откройте http://127.0.0.1:4173

`npm install` нужен для автотестов и локальных копий JSZip, Cytoscape и Lucide. Если каталог `vendor` уже заполнен, для запуска достаточно `node server.mjs`.

Не открывайте `index.html` двойным щелчком. Модули и служба для работы без сети требуют адрес `http://`.

После первой загрузки страница запоминается в браузере. Данные кампаний и так лежат в IndexedDB, поэтому стол остаётся доступен без интернета.

Проверка хранения:

```bash
npm test
```

## Резервные копии

Экспорт на карточке игры или в разделе «Настройки» скачивает ZIP. В архиве лежат `manifest.json`, `data.json` и папка `images` со всеми вложениями, включая обложку и портреты.

Храните эти файлы вне браузера: на диске, флешке или в своей папке. Очистка данных сайта, другой браузер или другой профиль компьютера не видят IndexedDB и без архива кампанию не вернуть.

Импорт читает ZIP, проверяет, что это архив StoryKeeper, и сверяет версию формата. Если архив новее программы, импорт останавливается и ничего не записывает. Успешный импорт создаёт отдельную игру и не затирает уже открытые кампании.

Дублирование на главном экране делает такую же копию внутри этого браузера.

Удаление игры спрашивает подтверждение и стирает её отдельную базу.

## Пример

Кнопка «Пример игры» создаёт кампанию «Дом на Вересковой улице»: локации, персонажей с темами разговора, улики, двух игроков, связи, сессию и заметки ведущего.

## Что реализовано

- Список кампаний: создание, правка, обложка, открытие, копия, экспорт, импорт, удаление с подтверждением.
- У каждой игры своя база IndexedDB. Записи разных игр не смешиваются.
- Разделы: обзор, локации, персонажи, улики и предметы, игроки, отношения, журнал сессий, заметки, настройки.
- У локации есть описания, изображения, секреты, события, люди, связанные места, теги и находки со статусом. Прогресс показывается как «найдено/всего».
- У персонажа есть биография, речь, знания, секреты и произвольные темы разговора.
- Улики связываются между собой, с местами и людьми. Статус сохраняется сразу.
- Карточки игроков: персонаж, инвентарь, сведения прямо с сессии, отношения.
- Схема отношений на Cytoscape: тип, описание, близость, публичность. Клик по линии открывает описание. Положение узлов запоминается.
- Журнал сессий и свободные заметки со связями.
- Поиск по текущей игре открывает найденную карточку.
- Режим ведущего: крупный текст, быстрые заметки, отметки улик, поиск. Список локаций и персонажей можно скрыть, чтобы расширить текст; заметки и отметки улик при этом остаются.
- Автосохранение текста примерно через 500 мс. Статусы, флажки и другие переключатели пишутся сразу.
- В шапке видны состояния «Сохранение...», «Все изменения сохранены» и «Ошибка сохранения». Ошибку можно повторить щелчком по статусу.
- Перед уходом со страницы незаписанный текст отправляется в базу.
- Изображения лежат в IndexedDB как байты, не как временные ссылки.
- Версия формата архива и миграция базы: при открытии старой структуры добавляются недостающие хранилища и индексы, старые записи остаются.
- Автотесты покрывают изоляцию баз, байты изображений, экспорт и импорт, отказ от чужого архива, миграцию, удаление связей и пример кампании.

## Ограничения

- Данные привязаны к браузеру и профилю. Другой компьютер увидит игру только через ZIP.
- Две вкладки с одной кампанией не блокируют друг друга: сохранится последняя запись.
- Нет учётных записей, общей игры по сети и истории версий карточки. Точка восстановления — экспорт.
- Текст обычный, без жирного шрифта и списков в полях.
- Поиск ищет подстроку, без учёта падежей.
- Схема сама раскладывает узлы. После перетаскивания положение сохраняется, но на печать не выводится.
- Файл изображения больше 15 МБ не принимается, чтобы не забить хранилище браузера.
- В приватном режиме Safari IndexedDB может быть недоступен.
- Служба для офлайна кэширует оболочку. Если программа обновилась, а в кэше осталась старая копия, обновите страницу при включённой сети.
